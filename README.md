# Timo Tautenhahn

**Twenty years between customers and engineers. Now I build the AI systems myself, and measure them.**

I design and build AI and data systems for real users: text-to-SQL, multimodal pipelines, and the evaluation harnesses that show whether any of it is ready for production. I write the code, and I can explain the trade-offs to the people who sign off on it.

## What I work on

- **Evals before claims.** Execution-based scoring instead of string matching, so a demo result survives contact with real data.
- **Grounded answers on enterprise data.** Text-to-SQL that is given the live schema and judged by the rows it returns.
- **Multimodal pipelines.** Crawl, tag with a vision model, and make a visual library searchable by what the images show.
- **Software for people, not demos.** An offline speech board for people who cannot currently speak, built phone-first and private by design.

## How I work

- Start from the decision the user has to make, not from the model.
- Measure before I claim. If there is no eval yet, the README says so.
- Prototype fast, then make it boring: configuration over hardcoding, no secrets in code, tests.

Two decades as solutions architect and field CTO for large enterprises across data, analytics and AI.
